This is my personal portfolio website built to display my technical skills, projects and exprience. 
It is completely built from scratch using HTML and CSS.
I have also used JavaScript in certain places to make the design more visually appealing. 
No libraries or frameworks have been utilised. 


Some features of my portfolio:


- Responsive UI compatible on mobiles, tablets and desktop
- Typewriter animation
- Scroll triggered decorative elements
- Scrollable projects row with hover overlays on project cards
- Contact form with mailto integration
