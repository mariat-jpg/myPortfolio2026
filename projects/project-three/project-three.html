StyleMe - AI Powered Outfit Recommendation Web App

Developed a full-stack web application that uses an LLM to generate personalized outfit recommendations based on the user's event and style profile, with real-time nearby store discovery using geolocation.


This project was built by my team and I for HackS'US V Hackathon 2026, at Rajagiri School of Engineering and Technology, Kochi, India.

Overview

Deciding what to wear to a specific event is a surprisingly common source of decision fatigue. StyleMe addresses this by combining AI-generated outfit suggestions with location-aware shopping recommendations, giving users both the "what to wear" and the "where to get it" in one place.

Key Features

  • Authenticated user flow with session persistence and onboarding
  • LLM-generated outfit recommendations tailored to the specified event
  • Occasion-to-vibe translation via a secondary low-latency Groq inference call
  • Real-time nearby store discovery using GPS + OpenStreetMap (zero paid API dependencies)
  • Distance calculation using the Haversine formula, sorted and limited to the top 6 closest stores

Implementation Approach

The app was built as a React + TypeScript SPA with a multi-layered architecture. User authentication and profile persistence are handled via Supabase, with a protected routing system that gates the main app behind login and a one-time onboarding flow to capture style preferences. Outfit recommendations are generated by calling the Groq API (Llama 3.1 8B) with the user's occasion as input. A separate LLM call translates the occasion into a vibe keyword (e.g. "formal wear", "streetwear"), which then drives a geolocation-based store search: the browser's native Geolocation API fetches the user's coordinates, and a live Overpass API query pulls nearby clothing stores from OpenStreetMap within a 5km radius such that no third-party maps API key required. Results are sorted by Haversine distance and returned to the user alongside the outfit suggestions.

Tech stack

TypeScript Vite Supabase (auth + database) Tailwind CSS shadcn/ui Groq API (Llama 3.1 8B) OpenStreetMap Overpass API Browser Geolocation API React Router TanStack Query
